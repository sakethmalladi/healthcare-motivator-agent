# Agentic Weightloss Motivator

A motivational health assistant that provides personalized health advice, web articles, and YouTube videos using OpenAI GPT models.

## Features

- Tracks user health progress (steps, calories, workouts, weight)
- Suggests next actions and motivation based on goals
- API-free DuckDuckGo search for health articles
- API-free YouTube search for fitness motivation videos
- Works with OpenAI GPT agents for personalized guidance
